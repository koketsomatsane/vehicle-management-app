<h1 align="center"> Vehicle Management App </h1>

<p align="center">
  A clean, lightweight Flutter application for tracking and managing your vehicles.
</p>

---

## Features

* **Add Vehicles.** Quickly register new vehicles by entering their **Registration Year**,
 **Make**, **Model**, and **Year**.
* **View Details.** Tap any vehicle in your garage list to inspect its full specifications on a dedicated details screen.
* **Edit Information.** Update existing vehicle details anytime to fix typos or keep records current.
* **Delete Vehicles.** Remove vehicles you no longer own with a simple delete action.

## Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
* [Flutter SDK](https://flutter.dev) installed on your system
* An Android Emulator, iOS Simulator, or physical device connected

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/koketsomatsane/vehicle-management-app.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd vehicle-management-app
   ```

3. **Install dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the app**
   ```bash
   flutter run
   ```
